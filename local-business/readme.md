# Local Business Prompts

This category contains OpenClaw prompts for finding and evaluating local businesses based on location, ratings, hours, and other criteria.

## Common Uses

* Finding highly-rated businesses near a location
* Filtering by price range, distance, or hours
* Checking appointment or reservation requirements
* Recurring searches as new options appear

## Search-First Recommendation

When researching local businesses:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Prefer official listings and verified review sources.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Find the best-rated business of a given type near a location.
* Filter by minimum rating, review count, and price range.
* Check which nearby options are open now or require appointments.
