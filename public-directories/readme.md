# Public Directories Prompts

This category contains OpenClaw prompts for researching information from public directories, public records, official listings, business registries, and government databases.

## Common Uses

* Looking up public records or registries
* Verifying business or organization details
* Searching official listings by location or category
* Compiling information from publicly accessible sources

## Search-First Recommendation

When researching public directories:

1. Search first.
2. Follow Search-First rules.
3. Use only publicly accessible, official sources.
4. Clearly note the source of each piece of information.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Look up information on a subject, organization, or business.
* Search official registries by industry or location.
* Compile publicly available reference information on a topic.
