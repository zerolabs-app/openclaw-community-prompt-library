# News Prompts

This category contains OpenClaw prompts for monitoring news related to a topic, industry, company, location, or event.

## Common Uses

* Ongoing monitoring of a topic, company, or industry
* Recurring news digests
* Filtering by source type or region
* Tracking developments over a defined time period

## Search-First Recommendation

When monitoring news:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Prefer original reporting over aggregators.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Monitor news about a specific topic, company, or region.
* Set a minimum number of stories per report.
* Filter by source type or news category.
* Run as a recurring task for ongoing coverage.
