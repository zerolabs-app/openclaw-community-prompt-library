# YouTube Prompts

This category contains OpenClaw prompts for YouTube channel research, trend discovery, and content strategy research.

## Common Uses

* Trend and content discovery
* Channel research by subscriber range
* Content idea generation
* Audience interest research

## Search-First Recommendation

When researching YouTube trends:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Gather evidence from public sources.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Research trending content within a topic or niche.
* Discover channels within a subscriber range.
* Filter by content type, region, or audience type.

Community contributions are welcome.
