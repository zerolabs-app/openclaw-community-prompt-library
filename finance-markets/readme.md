# Finance & Markets Prompts

This category contains OpenClaw prompts for tracking market data, economic indicators, and financial signals that change frequently.

## Common Uses

* Tracking yields, rates, and inflation-adjusted figures
* Options market positioning (max pain, open interest)
* Recurring market monitoring and alerts
* Comparing current data to prior periods

## Search-First Recommendation

Financial figures inform real financial decisions. Always:

1. Search first for the most current data.
2. Follow Search-First rules.
3. Prefer original sources (exchanges, official data providers) over aggregators.
4. Note the as-of date/time on every figure returned.
5. Flag when sources disagree.

## Example Prompt Types

* Track real (inflation-adjusted) Treasury yields across maturities.
* Find today's max pain price level for a given options ticker.
* Compare current market data to a prior period.
* Monitor a specific economic indicator on a recurring schedule.
