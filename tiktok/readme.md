# TikTok Prompts

This category contains OpenClaw prompts for TikTok trend research, viral content discovery, and creator/audience research.

## Common Uses

* Trend and viral content discovery
* Creator research by follower range
* Content idea generation
* Audience and niche research

## Search-First Recommendation

When researching TikTok trends:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Gather evidence from public sources.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Research trending content within a topic or niche.
* Discover creators within a follower range.
* Filter by content type, region, or video length.
