# Real Estate Prompts

This category contains OpenClaw prompts for finding real estate matching specific criteria such as location, budget, and property features.

## Common Uses

* Searching listings by price, size, and location
* Filtering by bedrooms, bathrooms, lot size, and HOA limits
* Recurring searches for new listings
* Comparing properties across criteria

## Search-First Recommendation

When researching real estate:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Prefer official listing sources.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Find properties matching budget, size, and location criteria.
* Filter by minimum bedrooms, bathrooms, or lot size.
* Set a maximum HOA fee or distance from a location.
* Run as a recurring task to catch new listings.
