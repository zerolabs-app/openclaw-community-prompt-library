# Vehicles Prompts

This category contains OpenClaw prompts for finding cars, trucks, and motorcycles matching specific criteria.

## Common Uses

* Searching listings by make, model, and year range
* Filtering by budget, distance, and required features
* Recurring searches for new listings
* Comparing options across trims and engines

## Search-First Recommendation

When researching vehicles:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Prefer official listing sources.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Find cars or trucks matching make, model, and budget criteria.
* Find motorcycles matching engine type and feature criteria.
* Set a maximum distance from a ZIP code.
* Run as a recurring task to catch new listings.
