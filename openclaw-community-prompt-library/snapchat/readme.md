# Snapchat Prompts

This category contains OpenClaw prompts for Snapchat research, trend discovery, creator research, and content ideas.

## Common Uses

* Trend and creator discovery
* Content idea generation
* Audience interest research
* Regional and niche trend monitoring

## Search-First Recommendation

When researching Snapchat trends:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Gather evidence from public sources.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Research trends within a topic or niche.
* Discover creators by size, region, or content type.
* Generate content ideas based on current trends.
