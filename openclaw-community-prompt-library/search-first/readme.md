# Search-First Prompts

This category contains the Search-First methodology — the standard OpenClaw research workflow that other prompts in this library build on.

## What Is Search-First?

Gather evidence first. Analyze second. Research should be driven by evidence, not assumptions.

## Core Principles

* Search first.
* Gather evidence.
* Verify information when practical.
* Prefer original sources.
* Analyze after evidence collection.
* Clearly distinguish facts from assumptions.

## When To Use This

Reference this methodology when building or adapting prompts in any other category, especially for research, monitoring, or reporting tasks where accuracy matters.

Community contributions are welcome.
