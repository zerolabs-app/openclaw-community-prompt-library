# Travel Prompts

This category contains OpenClaw prompts for finding flights and other travel options matching specific criteria.

## Common Uses

* Finding the cheapest fares matching date and passenger criteria
* Comparing options across airlines and routes
* Recurring fare-watching for price drops

## Search-First Recommendation

When researching travel:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Prefer official airline or booking sources.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Find the cheapest round-trip airfare matching route and date criteria.
* Filter by number of passengers and preferences.
* Run as a recurring task to watch for fare drops.
