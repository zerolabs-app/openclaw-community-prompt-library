# Products Prompts

This category contains OpenClaw prompts for researching, comparing, and sourcing products — including retail products and wholesale/resale sourcing.

## Common Uses

* Comparing products by price, features, and reviews
* Finding wholesale or bulk sourcing options
* Filtering by budget, brand, and required features
* Recurring price or availability checks

## Search-First Recommendation

When researching products:

1. Search first.
2. Follow Search-First rules.
3. Use the configured search provider from Search Defaults.
4. Prefer official retailer or manufacturer listings.
5. Use AI analysis after research is complete.

## Example Prompt Types

* Research and compare products against a budget and feature list.
* Find wholesale or bulk sourcing options for resale.
* Filter by minimum rating, preferred brands, and excluded brands.
